# Bill of Materials (BOM)

This project requires the following components to assemble the audio control device.

| Component | Description | Quantity |
| :--- | :--- | :--- |
| Microcontroller | USB-HID capable board (e.g., Adafruit QT Py RP2040 or equivalent) | 1 |
| Rotary Encoder | Standard rotary encoder for volume control | 1 |
| USB Cable | USB-C or Micro-USB cable (matching the microcontroller board) | 1 |
| Hookup Wire | For connecting components to the microcontroller | As needed |
| 3D Printed Case | Printed from `3D Prints/Case.stl` | 1 |
| 3D Printed Cover | Printed from `3D Prints/Cover.stl` | 1 |
| 3D Printed Knob | Printed from `3D Prints/Knob.stl` | 1 |
| Breadboard | Connect the entire project | 1 |
| Wires | Connect components | As many as needed |
